# Aplicación Móvil - Prácticas Académicas

Este repositorio está destinado exclusivamente al desarrollo de las actividades, ejercicios y prácticas asignadas para la materia correspondiente en el marco de nuestra formación técnica.

## Propósito del Repositorio

El objetivo de este espacio es servir como entorno de trabajo colaborativo para aplicar conceptos de desarrollo móvil, implementar buenas prácticas de control de versiones con Git y registrar el progreso de las consignas prácticas dictadas por el docente.

## Tecnologías y Entorno

* **Lenguaje:** Java
* **IDE:** Android Studio (Giraffe / Versión actual)
* **Control de Versiones:** Git & GitHub (Estrategia de ramas: `main`/`production` y `develop`)
